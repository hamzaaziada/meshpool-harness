# Document summary

1. Read every file the user named with read_file or read_document. For long PDFs, read the table of contents or first pages first, then the sections that matter.
2. Write the summary in this order: what the document is and who it is for; the five to eight key points; numbers and dates that matter; decisions or asks; open questions or risks.
3. Quote short phrases only when the exact wording matters, with the page or slide number.
4. Keep it to one screen unless the user asks for more. Offer to save it as Word or PDF.
