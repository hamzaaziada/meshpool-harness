# Research brief

1. Restate the question in one sentence and list the three to five things you need to find out.
2. Search the web for each (web_search, then fetch_url or the browser tools for the pages that matter). Prefer primary sources: official sites, filings, documentation, papers.
3. Note every fact with its source URL. Do not state numbers you could not find a source for.
4. Write the brief in Markdown: a two-sentence answer first, then a short section per finding, then a Sources list.
5. Save it as a Word file with make_document (Meshpool Office) in the project folder, named after the topic.
6. Reply with the answer in two sentences and the file name.
